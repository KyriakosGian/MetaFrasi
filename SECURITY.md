# Security

Never include API keys or sensitive page content in public reports. For a security issue, use GitHub's private vulnerability reporting feature if it is enabled. Otherwise open an issue asking for a private contact channel without publishing exploit details or secrets.

MetaFrasi sends requested text directly to Google Gemini. It does not encrypt locally stored keys. Revoke an exposed key in Google AI Studio. See the [privacy policy](docs/privacy.html) for data flow and deletion controls.
