# Chrome Web Store draft

Status: prepared for version 0.1.4. Not submitted. Final live-user testing is required.

## Name

MetaFrasi

## Short description

Translate selected text or read a translated summary with your own Google Gemini API key.

## Detailed description

Read a word, sentence or passage in your preferred language without leaving the page.

MetaFrasi is a small, open-source reading assistant for Chrome. Double-click a word or select a passage to reveal the Translate button. Choose your usual language, try another language for that selection, or request a translated summary.

Intended for adults using Gemini for professional or business purposes. Google requires Paid Services when API clients are offered to users in the EEA, Switzerland and the UK.

FEATURES

- One-click translation into your saved target language.
- Another target language for the current selection.
- Summarize and translate longer passages.
- Original-text reference and copyable results.
- Move and resize the result window beside your document.
- Preserve bullets, numbering and paragraph structure.
- Customize translation and summary instructions in Settings.
- View elapsed time, model and API-reported tokens.
- Guided Gemini API key setup and text-model discovery.
- Clear saved-key status and a manual connection check.
- Dark, light and system themes.
- Temporary result caching and a pause control.
- Editable fields are excluded so writing tools such as TypePilot can coexist.

YOUR KEY, YOUR PROJECT

MetaFrasi requires your own Google Gemini API key. The extension is free. Google offers eligible free-tier access and paid plans, subject to its current terms, region, model availability and usage limits. A paid project can incur Google charges. MetaFrasi does not activate billing or switch models automatically during translation.

PRIVACY

Requests go directly from the extension to Google. There is no MetaFrasi backend, advertising or analytics. Only the selected text and translation instructions are submitted when you choose an action. Your key stays in local extension storage and is not synced. Google's data handling terms apply to its service.

SCOPE

Version 0.1 translates selected text on supported HTTP and HTTPS webpages. It does not translate full pages, images, videos or PDF documents. Chrome-protected pages are not accessible. AI translations and summaries should be reviewed for accuracy.
