Support

Install the test release

  1. Download the ZIP from GitHub Releases and extract it.
  2. Open chrome://extensions in Chrome and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Open MetaFrasi Settings, connect your Gemini key, choose a language and save your preferences.
  5. Reload webpages that were already open before installation.

The button does not appear

Check that MetaFrasi is enabled in Settings. Select normal webpage text, not text inside a writing field. Chrome's internal pages, the Chrome Web Store, the built-in PDF viewer and some embedded documents are restricted. Try a regular article and reload the tab after an extension update.

Google rejects the key or model

Open Google AI Studio to check your project's eligibility, key restrictions and model access. Reconnect the key in Settings to refresh the list. A listed model may still require billing or available quota.

A rate or usage limit is reached

Wait before trying again and check your project's limits in AI Studio. Limits can be shared with other applications using the same Google project, including TypePilot. MetaFrasi never switches models or enables paid billing automatically.

A result looks wrong

Check the original text in the result panel. Try a complete sentence for an ambiguous word. AI translations and summaries can omit nuance or make errors, so review the result before relying on it.

Report a problem

Open a GitHub issue ↗

Include your Chrome version, extension version, steps to reproduce and a neutral sample passage. Remove private content from screenshots. Never include your API key.
