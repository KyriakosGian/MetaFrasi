Privacy Policy

This policy describes MetaFrasi version 0.1, an open-source Chrome extension developed by KyriakosGian.

What the extension does

MetaFrasi translates text you select on a webpage or produces a translated summary. Selecting text displays a control. It does not send a request to Google until you choose a translation or summary action.

Who this is for

MetaFrasi is intended for adults using Gemini for professional or business purposes. Google requires Paid Services when API clients are made available to users in the EEA, Switzerland or the UK. Eligibility is governed by the Google API terms.

Data sent to Google

At your request, the extension sends the selected text, target language, task instructions including your saved custom instructions, chosen model identifier and your API key directly to the Google Gemini API. Connecting or refreshing your key sends the key to Google to list models. The extension does not send the page URL, full page, browsing history or other unselected page content. As the receiving service, Google can receive connection information such as your IP address.

Google processes these requests under its own Gemini API terms and Privacy Policy. Data handling, retention and use for product improvement depend on the applicable service, account and region. Review Google's terms before sending confidential or personal content.

Data stored in your browser

Your API key, model list and preferences, including custom translation instructions, are stored in chrome.storage.local. They are not synced by MetaFrasi. Access to this storage is restricted to trusted extension contexts. MetaFrasi does not encrypt the API key and cannot protect it from someone with access to your browser profile or device.

Up to 40 recent results can be held in the service worker's memory for up to 20 minutes. This cache is temporary, can disappear sooner when Chrome stops the worker, and is not saved as a persistent reading history. Entries expire when accessed after their limit. No selected text is written to extension storage.

Permissions

The storage permission saves your preferences and key. Access to generativelanguage.googleapis.com permits direct API requests. Content scripts run on HTTP and HTTPS pages to detect your text selection and display the translation control. Editable fields are excluded. Chrome prevents access to certain protected pages.

No developer-operated data service

MetaFrasi has no developer-operated server, analytics, advertisements or tracking. The developer does not receive your selected text or API key through the extension. Data is not sold.

Your controls

You can pause the extension, remove your saved key or clear temporary results in Settings. Removing a key cancels active extension requests where possible, but cannot recall data already received by Google. Uninstalling MetaFrasi removes its local extension storage. You can revoke a key in Google AI Studio.

This website

The presentation website has no analytics or advertising scripts. Its interactive example uses fixed sample text and does not call Gemini. When the site is hosted on GitHub Pages, GitHub handles hosting requests under its own Privacy Statement. External links take you to services with their own policies.

Questions and changes

Contact the developer through the GitHub issue tracker. Do not post API keys, confidential text or unredacted screenshots in public issues. Material policy changes will be recorded in the repository changelog and reflected in the date above.
