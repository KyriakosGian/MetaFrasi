MetaFrasi follows the same simple approach as TypePilot. You control the API key, model and default language.

Installation guide ↗
  1. 1

    Install the extension

    Download the release ZIP, extract it, then open chrome://extensions. Enable Developer mode and choose Load unpacked.

  2. 2

    Connect Google Gemini

    Create a key in Google AI Studio. Paste it into MetaFrasi Settings and connect. Eligible free-tier and paid projects can be used.

  3. 3

    Make it yours

    Choose a text model and your preferred language. Save your preferences, open a webpage and select a passage.

BEFORE YOU START

A few clear answers.

Is MetaFrasi free?

The extension is free and released under the MIT License. Gemini is a separate Google service. Free-tier availability, model access and quotas depend on your Google project and current terms. Paid projects can incur charges. See Google's pricing.

What leaves my browser?

When you request a translation or summary, your selected text, target language, task instructions and API key go directly to Google. MetaFrasi does not send the full page, its URL or your browsing history. Read the Privacy Policy.

Does it work with TypePilot?

MetaFrasi is designed for reading. It skips editable fields so writing assistants such as TypePilot can handle text you are composing.

Where does it work?

On supported HTTP and HTTPS webpages in desktop Chrome. Chrome's internal pages, the Chrome Web Store and the built-in PDF viewer restrict extension access. Images, video subtitles and full-page translation are outside this first release.

Can I use it without an API key?

Version 0.1 requires your own Gemini API key. The example above is a static demonstration. It does not connect to Google.

Is it in the Chrome Web Store?

This is an early version for local testing. Chrome Web Store submission will follow testing. No store listing is available yet.
